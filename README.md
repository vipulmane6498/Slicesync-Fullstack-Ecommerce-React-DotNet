# Slicesync-Fullstack-Ecommerce-React-DotNet
SliceSync is a full-stack e-commerce platform developed using ASP.NET Core Web API and React, implementing secure JWT authentication, product management, cart functionality, order processing, and a clean, scalable architecture.
